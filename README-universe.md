# UNIVERSE

Author: **L1ghtXr**

15 OSINT tools. Pure Go, stdlib + real public feeds. No AI/ML.

## Build
```bash
go build -o universe ./cmd/universe
./universe help
```

## Tools
osintcore, geoint, domaintrace, ipintel, userfinder, mailtrace,
**phototrace** (ELA, noise, chroma, double-JPEG, copy-move, ghost),
socialmap, linktrace, metatrack, breachwatch, darkintel, certtrace,
geoarchive, entitylink.
